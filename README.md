# 🍵 Abartılı Çay Molası Simülatörü

## Bilimsel Özet

Bu repository, insanlığın en temel ihtiyacı olan **çay demleme** işlemini bilimsel olarak sonsuza kadar uzatmak amacıyla geliştirilmiştir. 

Yıllar süren (asılında 3 dakika) araştırmalar sonucunda, en optimal çay demleme süresinin **hiç bitmemek** olduğu kanıtlanmıştır. Bu simülatör, o teoriyi pratiğe dökmektedir.

### Özellikler

- ✅ Sonsuz döngü (matematiksel olarak güzel)
- ✅ Rastgele bekleme süreleri (sürpriz faktörü)
- ✅ Aşırı ciddi terminal çıktıları
- ✅ Ctrl+C ile durdurulabilir ama pişman olursunuz
- ✅ Çay içmez, sadece demler

### Kurulum ve Çalıştırma

```bash
python3 cay_demle.py
```

**Uyarı:** Bu program gerçek çay üretmez. Eğer susuz kaldıysanız lütfen gerçek su için.

### Bilimsel Katkı

Bu proje, çay molası verimliliğini %0 artırmıştır. Bu da bir başarıdır.

### Lisans

Bu kod herkese açıktır. Çay demlemek yasaktır (değildir).
